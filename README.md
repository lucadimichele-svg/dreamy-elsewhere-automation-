# Dreamy Elsewhere 🌙

Unabhängiges Automationsprojekt für **@dreamy_elsewhere**.

## Konzept
- Vier Cozy-&-Dreamy-Reels täglich vom 17.11. bis 14.12.2026, anschließend zwei täglich.
- Je Reel fünf 1080×1920-Bilder und eine englische Auswahlfrage.
- Keine subjektive Bildbewertung oder manuelle Freigabe.
- Keine Änderungen an Blinkpuzz oder Vibsnaxx.

## Status (16.11.2026)
**Noch nicht vollständig automatisiert.** Bildgenerierung im Chat ist nicht automatisch über GitHub Actions aufrufbar. Eine zulässige, verfügbare Musikquelle und die Buffer-API-Konfiguration fehlen. Bis dahin: **keine automatische Veröffentlichung**.

Hinweis: Das Repository hat im GitHub-Namen tatsächlich ein abschließendes `-` (dreamy-elsewhere-automation-). Alle späteren URLs müssen genau diesen Namen verwenden.
