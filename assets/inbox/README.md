# Bilder hier bereitstellen

Pro Reel exakt fünf Fotos mit wenigstens 1080×1920 Pixeln in den Ordner
`assets/inbox/YYYY-MM-DD_S1/`, darin `01.jpg` bis `05.jpg`.

Startphase: S1–S4 pro Tag. Ab 15. Dezember: S1–S2.
Die Motive werden **nicht subjektiv bewertet**. Fehlt ein vollständiger Bildsatz,
wird dieser Reel-Slot ausgelassen; niemals Inhalte für einen anderen Account posten.

Die Bildgenerierung über ChatGPT ist in diesem GitHub-Projekt **noch nicht automatisch angeschlossen**.
